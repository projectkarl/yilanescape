# High-poly QA gate

Reject an asset or capture if any of the following occurs:
- visible faceting on hero-car bodywork, wheels, signal lenses or streetlight poles at normal camera distance;
- hero car below 150k source triangles without a documented replacement high-res Nanite mesh;
- crowd proxy used within hero-dialogue / close pedestrian range;
- random placement of streetlights or signals in Tier A zones when a verified real-world point exists;
- stretched or blurry materials used to disguise missing geometry;
- motion blur, film grain or depth-of-field used to hide asset defects;
- Nanite enabled on movable/skeletal gameplay content without verifying the engine/platform behavior;
- visual mesh used as vehicle collision mesh.

### Capture set
Every Tier A block must have:
1. daylight static 4K screenshot;
2. overcast/rain 4K screenshot with readable facade detail;
3. vehicle stationary close-up at 3–5 m;
4. pedestrian close-up at 2–3 m;
5. intersection shot showing lane markings, signal positions and streetlights.
